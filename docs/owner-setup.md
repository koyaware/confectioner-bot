# Настройка владельца

## Что нужно сделать кондитеру

1. Собрать магазин в коде:
   `npm run tenant:create -- --slug <slug> --name "<Название>" --token "<token>"`

   Скрипт выведет ссылку для привязки владельца.

2. Открыть ссылку `t.me/<bot>?start=claim_<code>` в Telegram и нажать `/start`.
   После этого `ownerTelegramId` привяжется к магазину.

3. Настроить магазин в `/menu`:
   - заполнить FAQ и тексты;
   - загрузить товары и категории;
   - задать режим «не принимаю заказы» при необходимости.

4. Настроить Instagram:
   - вставить ссылку бота в шапку профиля;
   - или использовать метки из раздела «Ссылки для Instagram».

## Демо-бот

Для показов используется демо-магазин из демо-данных:

1. `npm run seed` — создать демо-магазин.
2. `npm run dev` — запустить бота.
3. Нажать `/start` в боте.

Для внешнего показа сократите набор магазинов и используйте только публичного демо-бота.
