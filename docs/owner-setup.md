# Инструкция для владельца

Этот файл объясняет, как подключить и пользоваться ботом,
без команды и программирования.

## 1. Что нужно сделать в Telegram

1. Откройте @BotFather.
2. Отправьте `/newbot`.
3. Придумайте имя бота, например `Магазин Ани_bot`.
4. Придумайте username, например `ani_cakes_bot`.
5. BotFather покажет вам токен — это длинная строка вида:
   `1234567890:AA...`.

Сохраните токен и отправьте его разработчику или вставьте в локальный конфиг.
Никому постороннему токен не сообщайте. Если токен утёк — смените его в @BotFather.

## 2. Что должен сделать разработчик

Сначала нужны подготовленные env-переменные. Выполните один раз:

```bash
cp .env.example .env
# заполнить APP_SECRET и SUPERADMIN_TELEGRAM_ID
set -a && source .env && set +a
```

Потом завести магазин в системе командой:

```bash
npm run tenant:create -- \
  --slug anna-cakes \
  --name "Магазин Ани" \
  --token "1234567890:AA..."
```

Команда выведет ссылку вида:

```
t.me/ani_cakes_bot?start=claim_xxxxx
```

Перед открытием ссылки запустите приложение:

```bash
npm run dev
```

После запуска откройте ссылку в Telegram и нажмите Start.
После этого именно ваш Telegram-аккаунт станет владельцем магазина.

## 3. Как пользоваться как владелец

Напишите боту:

```
/menu
```

Появится меню владельца:

- `Заказы` — принять, отклонить, предложить другую дату, статусы.
- `Каталог` — товары, категории, цены, опции.
- `FAQ` — вопросы-ответы.
- `Настройки` — тексты, реквизиты, сроки.
- `Календарь` — загрузка, закрытые дни.
- `Ссылки для Instagram` — метки источников, QR.
- `Статистика` — 7/30 дней.

## 4. Клиентский путь

Клиент открывает ссылку из Instagram, нажимает Start,
видит каталог, добавляет товар в корзину, выбирает дату и оформляет заказ.

После заказа владельцу приходит карточка заказа.
Кнопки:

- `Принять` — клиент получает подтверждение.
- `Отклонить` — клиент получает отказ и причину.
- `Другая дата` — бот предложит новый вариант.
- `Написать клиенту` — откроется диалог с клиентом.

## 5. Instagram

В шапке профиля поставить:

```
https://t.me/ani_cakes_bot
```

Или получить готовые тексты:

```
/menu
Ссылки для Instagram
Новая метка
...
```

Для каждого источника будет своя ссылка:

```
https://t.me/ani_cakes_bot?start=reels-cake
```

Эту ссылку можно вставлять в шапку, закреплённый комментарий или автоответ директа.

## 6. Если вы не хотите принимать заказы

```
/menu
Настройки
Переключить приём заказов
```

Бот покажет текст режима перегруза и перестанет принимать новые заказы,
но каталог и FAQ останутся доступны.

## 7. Свои данные

Команда:

```
/deleteme
```

Обезличат ваши данные: имя, телефон, адрес, комментарий.
Агрегаты продаж при этом сохраняются.

## 8. Если что-то сломалось

1. Проверьте интернет и перепишите боту `/menu`.
2. Если бот не отвечает — перезапустите процесс `npm run dev`.
3. Если после перезапуска бот не отвечает — проверьте токен и `.env`.

Для восстановления БД используйте `docs/restore.md`.
