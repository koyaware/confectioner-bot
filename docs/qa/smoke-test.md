# Смок-тест: ручная проверка бота

Нужно: тестовый бот-магазин + два аккаунта Telegram (клиент и владелец).
Отмечай `[x]` пройденные шаги. Любое отклонение от «Ожидается» — записывай в `bugs.xlsx`.

## SMOKE-01. Клиент: каталог → корзина → заказ

1. [ ] Клиент пишет `/start` → видишь приветствие и кнопки: Каталог, Корзина, Мои заказы, FAQ, Написать мастеру.
2. [ ] Жмёшь «Каталог» → список категорий. Открываешь категорию → список товаров.
3. [ ] Открываешь товар → фото, цена, опции, количество. Выбираешь опцию, жмёшь «В корзину» → тост-подтверждение, остаёшься в карточке.
4. [ ] Жмёшь «Корзина» (или «Перейти в корзину») → строка с ценой и итогом. Проверь `+`/`−`.
5. [ ] «Оформить заказ» → календарь. Недоступные даты помечены и не нажимаются.
6. [ ] Выбираешь дату → вводишь время (можно пропустить) → «Доставка» → вводишь адрес → отправляешь контакт кнопкой → пропускаешь комментарий → пропускаешь фото → видишь сводку заказа.
7. [ ] Жмёшь «Подтвердить» → «Заказ №1 отправлен». Корзина пустая.
8. [ ] Дважды быстро жмёшь «Подтвердить» (если успел) → заказ всё равно один.

Ожидается: один экран = одно сообщение, везде есть «Назад», корзина очистилась после заказа.

## SMOKE-02. Владелец: приём заказа и оплата с чеком

1. [ ] Владельцу пришла карточка заказа: состав, дата, адрес, контакт, сумма, предоплата.
2. [ ] Жмёшь «Принять» → клиенту пришло «принят в работу», тебе — реквизиты у клиента.
3. [ ] Клиент видит сумму предоплаты, реквизиты и кнопку «Я оплатил». Жмёшь её → просят прислать чек.
4. [ ] Клиент отправляет **текст** вместо чека → бот просит ещё раз и объясняет формат.
5. [ ] Клиент отправляет **фото** чека → владельцу приходит фото с кнопками «Оплата верна» / «Оплата не пришла».
6. [ ] Жмёшь «Оплата верна» → статус «Подтверждён», клиент уведомлён.
7. [ ] (Второй круг) На новом заказе после чека жмёшь «Оплата не пришла» → заказ вернулся в ожидание оплаты, клиент может прислать другой чек.

Ожидается: чек приходит именно фото/файлом, а не текстом; клиент всегда понимает, что делать дальше.

## SMOKE-03. Статусы и отмены

1. [ ] На подтверждённом заказе жмёшь «Готов» → потом «Завершён». Клиент получил оба уведомления.
2. [ ] Клиент открывает «Мои заказы» → видит свои заказы со статусами, чужих нет.
3. [ ] Клиент отменяет новый заказ через «Отменить» → выбирает причину → заказ пропал из списка, владельцу пришло уведомление.
4. [ ] Владелец на новом заказе жмёшь «Отклонить» → выбираешь причину → клиент получил отказ с причиной.
5. [ ] Владелец на новом заказе жмёшь «Другая дата» → красивая сетка месяца → выбираешь дату → клиент получил предложение.
6. [ ] Клиент принимает дату → заказ принят автоматически. (Вариант: отклоняет → тебе пришло уведомление.)

Ожидается: отменённые заказы скрыты из «Мои заказы»; каждый переход статуса доходит до клиента.

## SMOKE-04. Язык и валюта (новая фича)

1. [ ] Владелец: `/menu` → Настройки → видишь строки «🌐 Язык интерфейса: Русский» и «💰 Валюта: ...».
2. [ ] Жмёшь язык → пикер «Русский / Oʻzbekcha». Выбираешь `Oʻzbekcha` → список настроек **уже на узбекском**.
3. [ ] Жмёшь валюту → пикер `₽ · RUB / ₸ · KZT / UZS`. Выбираешь `₸` → валюта сменилась, тексты остались узбекскими.
4. [ ] Возвращаешь язык `Русский` + валюту `₽` → всё снова по-русски (комбинации независимы).
5. [ ] Клиент открывает каталог → цены в текущей валюте магазина.

Ожидается: язык и валюта переключаются независимо; после смены нет смеси языков на одном экране.

## SMOKE-05. Связь, FAQ, календарь владельца

1. [ ] Клиент жмёт «Написать мастеру» → пишет вопрос → владельцу пришло сообщение с шапкой (имя, заказ) и кнопкой «Блокировать».
2. [ ] Владелец отвечает **reply** на это сообщение → ответ дошёл клиенту, тебе — «Отправлено клиенту».
3. [ ] Клиент пишет текст просто так (вне диалога) → сообщение удалилось, пришла подсказка с кнопкой «Написать мастеру».
4. [ ] Клиент открывает FAQ → вопрос → ответ → «Назад».
5. [ ] Владелец: Календарь → выбираешь дату → закрываешь день → у клиента эта дата стала недоступной. Открываешь обратно.
6. [ ] Владелец: Каталог → добавляешь товар с фото → он сразу виден клиенту. Скрываешь → пропал у клиента, у тебя остался.

Ожидается: отдельной кнопки «написать клиенту» у владельца нет — только reply; свободный флуд клиенту не уходит.

## SMOKE-06. Статистика и сводка

1. [ ] Владелец: Статистика → цифры за 7 дней; переключаешь на 30 → пересчиталось.
2. [ ] Проверь: новые клиенты, воронка, заказы по статусам, выручка — числа правдоподобные (сверь с заказами выше).
3. [ ] Суперадмин: `/status` → аптайм, боты, очередь джобов. `/tenants` → список магазинов.

Ожидается: кнопки 7/30 работают, цифры не нулевые после прогона SMOKE-01…05.
