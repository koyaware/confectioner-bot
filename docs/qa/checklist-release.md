# Release checklist (senior QA gate)

Прогоняется перед каждым пилотным включением. Любой красный пункт блокирует релиз.

## 1. Автоматические гейты

- [ ] `npm run lint` зелёный
- [ ] `npm run build` (`tsc`) зелёный
- [ ] `npm run format:check` зелёный
- [ ] `npm test` — все файлы зелёные, упавших 0
- [ ] `npm run load:sim` — `passed: true`, `p95Ms` < 200
- [ ] Миграции применяются на пустую БД (покрыто каждым тестом через `migrate()`)
- [ ] Upgrade-путь: новая миграция проверена на БД со старой схемой вручную

## 2. Контракты (tech.md — источник истины)

- [ ] Версия ядра поднята, changelog дописан до кода
- [ ] Схема §5 == `src/db/schema.ts` (таблицы, колонки, индексы)
- [ ] Типы §7 == `src/types.ts` + `src/i18n/index.ts` (`Lang`, `Strings`, `SessionData`, состояния)
- [ ] Колбэки §8.1: каждый задокументированный обрабатывается, каждый излучаемый задокументирован
- [ ] Джобы §8.2: типы и payload совпадают с `src/jobs/types.ts`
- [ ] zod-схема сессии принимает все поля `SessionData` (тест `session-schema.test.ts`)
- [ ] Словари `uz`/`kk` зеркалят `ru` (проверяет `tsc` + `i18n.test.ts`)

## 4. Только руками на живом боте (автоматы не видят)

- [ ] Фото товара реально отображается в карточке (подпись читается, кнопки жмутся)
- [ ] Кнопка «📱 Отправить контакт» открывает системный шаринг контакта
- [ ] Reply-клавиатура исчезает после шаринга/ввода/скипа (не висит)
- [ ] Чек-фото доходит владельцу как фото с кнопками
- [ ] Узбекский и казахский экраны читаются носителем (не машинный мусор)
- [ ] QR из «Ссылок» сканируется, ведёт на бота с меткой
- [ ] Дайджест приходит утром, кнопки открывают заказы

## 5. Данные и секреты

- [ ] В репозитории нет токенов, `data.db`, `.env` (проверить `git status`)
- [ ] `APP_SECRET` ≥ 32 символов, токены в БД шифрованы
- [ ] Бэкап свежий, восстановление по `docs/restore.md` проверялось в этом месяце
- [ ] `bugs.xlsx` — все новые строки имеют Resolution; `bugs.numbers` переимпортирован при расхождении

## 6. Откат

- [ ] Известна предыдущая зелёная ревизия (`git log`)
- [ ] Процедура: остановить процесс → заменить `data.db` из бэкапа → запустить → прогнать SMOKE-01
