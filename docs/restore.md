# Восстановление из бэкапа

## Ежедневный бэкап

Каждый день в 03:00 UTC планировщик создаёт джоб `backup.db` и отправляет файл БД в Telegram суперадмину как документ. Файл также кладётся в `./backups/backup-YYYY-MM-DD.db`.

Для отправки нужен хотя бы один запущенный бот. Хранятся последние 7 бэкапов, старые удаляются автоматически.

## Как восстановить

1. Остановить процесс бота.
2. Заменить текущий файл БД на файл из бэкапа.
3. Запустить процесс бота.

Пример:

```bash
# 1. Остановить процесс
pm2 stop confectioner-bot

# 2. Заменить файл БД
cp ./backups/backup-2026-10-02.db ./data.db

# 3. Запустить процесс
pm2 start confectioner-bot
```

## Проверка целостности

После получения файла из Telegram можно проверить его:

```bash
sqlite3 ./backup-2026-10-02.db "PRAGMA integrity_check;"
# должно вернуть: ok
```

## Проверка раз в месяц

Раз в месяц делать тестовое восстановление на копии:

1. Скопировать файл БД из Telegram в отдельную папку.
2. Указать путь к копии в переменной окружения `DATABASE_PATH`.
3. Запустить бота на этом файле.
4. Проверить, что бот стартует и показывает каталог.
