# Стадия 5: Источники, статистика и ежедневная сводка — статус

## Что сделано

- **5.1 Источники заказов** (`83a126e`)
  - Владелец может создать источник (вкладка Instagram) в настройках: «Ссылки для Instagram» → «Новая метка» → ввести название.
  - Для каждого источника бот генерирует короткую метку (`code`), ссылку вида `https://t.me/<bot>?start=<code>` и QR-код.
  - К каждому источнику показываются готовые тексты: шапка профиля, закреплённый комментарий, текст автоответа директа.
  - Файлы: `src/services/sources.ts`, `src/bot/owner/links.ts`, `src/bot/owner/edit-field.ts`, `tests/links.test.ts`.

- **5.2 Статистика** (`d5505b9`)
  - Владелец видит сводку за 7/30 дней: новые клиенты по источникам, события воронки, заказы по статусам, выручка по подтверждённым, среднее время до решения, экраны, где бот закрыл заказ без человека.
  - Файлы: `src/services/stats.ts`, `src/bot/owner/stats.ts`, `tests/stats.test.ts`.

- **5.3 Ежедневная сводка** (новое)
  - Каждый день в `digestHour` владелец получает в Telegram сообщение: сколько заказов на сегодня, на завтра, сколько ждут решения, сколько ждут оплаты.
  - Планировщик сам создаёт джобы `owner.daily_digest` с dedupe-ключом `digest:<tenantId>:<date>`.
  - Файлы: `src/services/digest.ts`, `src/jobs/handlers/daily-digest.ts`, `src/jobs/scheduler.ts`, `src/main.ts`, `tests/digest.test.ts`.
