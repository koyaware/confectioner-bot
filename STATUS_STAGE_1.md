## Контрактные заметки

- Новая текстовая цепочка `owner.edit_field` + `ownerDraft` для одношагового ввода владельца.
- Callback-коды для редакторов: `adm:cat:*`, `adm:prd:*`, `adm:faq:*`, `adm:set:*` в рамках таблицы 8.1 (`adm:*` дикие).
- `adm:*` обрабатывают только владельцы; не-владелец получает `answerCallback` с «Только владелец» и без побочных эффектов. Сценарный тест включён.
